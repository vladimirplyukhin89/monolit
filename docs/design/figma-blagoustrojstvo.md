# Figma: `/blagoustrojstvo` — moodboard и чек-лист

Краткий бриф перед макетом. Источники: wireframe `wireframes/home.md`, контент Tilda, референсы Karagay / Urban Green / LWLA / география.рф.

**Статус:** структура страницы собрана в коде (`src/pages/blagoustrojstvo.astro`). Фото — плейсхолдеры до файлов в `docs/content/media/`. Макет в Figma можно сверять с живой страницей.

**Цель страницы:** заявка (форма и звонок). Визуал поддерживает доверие и ясность услуг, не уводит в portfolio-театр.

## Moodboard: что смешиваем

| Слой | Откуда | Как выглядит на monolit |
|---|---|---|
| Ambient и плиты | география.рф | Фон страницы `--color-ambient-landscape` `#D5E8DA`; контент в крупных плитах на белом/`--color-bg`; радиусы `--radius-lg` / `--radius-xl` |
| Акцент | бренд | CTA и ссылки-акценты `#ED581F` на белом; текст `#2E2E2E` |
| Ритм секций | Karagay | Hero → trust → услуги → кейсы → FAQ → форма; без питомника/новостей/B2B |
| Фото | LWLA + Karagay | Крупный фото-якорь работ; без стикеров и оверлеев на hero |
| Chooser (контекст) | Urban Green | На этой странице chooser нет; ambient уже «landscaping»; в шапке — ссылка на ремонт |
| Шрифт | токены | Golos Text; H1 mobile ~32px, H2 ~26–30px; плотный line-height у заголовков |

### Не мешать в макет

- Chestnut / sage / cream как primary или фон страницы  
- 3D-интро, гориз. скролл, day/night toggle  
- Мелкая сетка карточек в первом экране  
- Декоративные звёзды, glassmorphism, emoji  
- Чёрная кнопка Contact вместо оранжевого CTA  

## Порядок секций (mobile-first)

Уточнение wireframe под благоустройство (Karagay-ритм + контент Tilda):

```

   в коде остров только если фильтр интерактивный; иначе статичные группы

7. About
   короткий текст + метрики (если не ушли в TrustStrip)

8. Testimonials
   плейсхолдеры, пока нет свежих отзывов; стиль — спокойная цитата (LWLA), не карусель с аватарками
```

## Фреймы в Figma — чек-лист

### Страница

- [ ] Mobile `390` (или `375`) — полная страница сверху вниз  
- [ ] Desktop `1440` (или `1280`) — та же структура, не другой сценарий  
- [ ] Ambient landscaping на обоих; шапка с телефоном и заявкой  

### Компоненты и состояния

- [ ] **Header** — default; бургер open (mobile); фокус клавиатуры на ссылках/кнопке  
- [ ] **Hero** — H1 + support + primary CTA; фото без оверлей-бейджей; контраст текста на фото (если текст на изображении — затемнение)  
- [ ] **TrustStrip** — 3 пункта; не иконочный ряд ради декора  
- [ ] **ServiceCard** — default / hover (desktop); цена «от» читаема  
- [ ] **BeforeAfter** — два кадра + подпись; или заглушка «gallery»  
- [ ] **CTABand** — оффер выезда/скидки + CTA  
- [ ] **CaseCard** — фото + название; сетка 1 col mobile / 2–3 desktop  
- [ ] **CaseFilter** (если есть) — idle / active chip; не обязателен для MVP-кода  
- [ ] **About** — текст + 1–2 метрики  
- [ ] **Testimonial** — цитата + имя/плейсхолдер  
- [ ] **FAQ** — collapsed / expanded  
- [ ] **LeadForm** — idle / focus / error / success; чекбокс согласия  
- [ ] **Button** — primary orange; secondary/text link; disabled  
- [ ] **Footer** — контакты, реквизиты, политика  

### Токены в стилях Figma (имена ≈ CSS)

- [ ] `color/bg`, `color/bg-muted`, `color/ambient-landscape`  
- [ ] `color/text`, `color/text-muted`, `color/primary`, `color/primary-contrast`, `color/border`  
- [ ] `radius/sm|md|lg|xl`  
- [ ] `font/golos` — Regular / Medium / Bold; размеры под mobile H1/H2/body  

### Доступность (проверить в макете)

- [ ] `#2E2E2E` на `#D5E8DA` — AA для текста  
- [ ] Белый на `#ED581F` — AA для кнопки  
- [ ] Фокус-кольцо видно на кнопках и полях  
- [ ] Один H1; секции — H2  
- [ ] `alt` у содержательных фото (подписать в макете или в заметке к фрейму)  

### SEO-заметки к фрейму (не верстка)

- [ ] Title / description черновик для `/blagoustrojstvo`  
- [ ] Canonical путь `/blagoustrojstvo`  
- [ ] JSON-LD Service — позже в коде; в Figma не рисовать  

## Контент-слоты (не выдумывать)

Брать из `references/monolit-tilda-content.md`: услуги и «от», FAQ-заголовки, офферы выезда/скидки, trust, контакты/реквизиты.  
Метрики `300+` / `5+ лет` — только если подтверждены; иначе плейсхолдер `[N+ объектов]`.  
Отзывы — плейсхолдеры, пока нет текстов заказчика.

## Связь с главной

Главная уже с `DirectionChooser`; эта страница — зафиксированный landscaping ambient.  
Не дублировать chooser. После выбора «Благоустройство» CTA ведёт сюда — в макете hero направления должен быть узнаваемым продолжением тизера с главной (те же услуги «от», тот же тон фото).

## Готово к передаче в код, когда

1. Mobile + desktop проходят чек-лист секций и состояний.  
2. Токены в Figma совпадают с `tokens.css` / `tokens-proposal.md`.  
3. Нет элементов из блока «Не мешать в макет».  
4. Контент — из Tilda/плейсхолдеров, не с чужих референсов.
