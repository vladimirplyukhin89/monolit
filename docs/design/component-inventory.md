# Инвентарь компонентов

Список уточнён после разбора география.рф, контента Tilda, wireframe главной (`wireframes/home.md`), референсов Karagay / Urban Green / LWLA и nikakih-nervov.ru (структура `/remont-kvartir`).

Столбец «Тип»: **статика** — `.astro` без клиентского JS, **остров** — React с JS.

Страницы MVP: `/`, `/blagoustrojstvo`, `/remont-kvartir`, `/politika-konfidencialnosti`.

## Отложено (не MVP главной / четырёх страниц)

| Компонент | Почему отложен |
|---|---|
| Calculator | Цены «от» в карточках и заявка достаточны на старте |
| Contacts и карта | Контакты в footer; отдельная страница контактов не в карте из 4 страниц |
| Breadcrumbs | Можно добавить на внутренние позже для SEO |
| Gallery и Lightbox | Достаточно сетки кейсов и BeforeAfter; lightbox — по необходимости |
| Day/Night toggle на фото | Есть у Karagay; нужен контент по освещению — не MVP |
| Project story page | Editorial layout LWLA; пока сетка кейсов на странице направления |
| BriefForm (расширенный бриф) | Urban Green; в MVP хватает короткой LeadForm |
| Awards / блог / Perspectives | Не в карте из 4 страниц; отвлекают от заявки |
| CaseFilter (остров) | Категории есть в данных; интерактивный фильтр — когда фото и кейсов станет много |
| `/remont-kvartir` контент | Блоки в коде; тексты/фото — плейсхолдеры до материалов заказчика |
| TeamIntro (дизайнеры) | Нет фото/ролей; при появлении контента — статика |
| PartnersStrip | Логотипы партнёров не в MVP |
| QuizCalculator | Отложен вместе с Calculator; хватает LeadForm |

## Решения по открытым вопросам

- **Цены:** отдельной страницы «Цены» нет; диапазоны «от» в карточках услуг + форма расчёта.
- **Два направления:** общая фирма (`#222222`, `#F28C28`); на главной tint только на карточках chooser (мята `#D5E8DA` / лаванда `#E2D8F0`); сайт — light/dark через ThemeToggle.
- **Главная обязательно:** Header (+ ThemeToggle), HeroIntro, DirectionChooser, DirectionPreview, TrustStrip, CTABand/LeadForm, Footer.
- **`/blagoustrojstvo`:** DirectionHero → TrustStrip → ServiceGrid → BeforeAfter → CTABand → CaseGrid → About → Testimonials → FAQ → LeadForm.
- **`/remont-kvartir`:** см. `wireframes/remont-kvartir.md` — PhotoHero → TrustStrip → PackageBand (опц.) → ServiceGrid → CaseGrid (inverse) → About → FAQ → LeadForm.
