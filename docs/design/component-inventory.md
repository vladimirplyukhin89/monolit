# Инвентарь компонентов

Список уточнён после разбора география.рф, контента Tilda, wireframe главной (`wireframes/home.md`) и референсов Karagay / Urban Green / LWLA.

Столбец «Тип»: **статика** — `.astro` без клиентского JS, **остров** — React с JS.

Страницы MVP: `/`, `/blagoustrojstvo`, `/remont-kvartir`, `/politika-konfidencialnosti`.

| Компонент | Назначение | Страницы | Тип | Статус |
|---|---|---|---|---|
| Header и навигация | Логотип, телефон, заявка; бургер; опциональная ссылка на другое направление | все | остров (мобильное меню) | в коде |
| Footer | Контакты, реквизиты, ссылка на политику | все | статика | в коде |
| HeroIntro | Бренд + общий оффер на главной | главная | статика | в коде |
| DirectionChooser | Два крупных раздела направлений (меню-fork как идея Urban Green, без 3D); смена `data-direction` и ambient | главная | остров | в коде (с preview) |
| DirectionPreview | Тизер услуг/фото/CTA выбранного направления | главная | часть DirectionChooser | в коде |
| DirectionHero | H1, оффер, CTA, чипы, фото-якорь страницы направления | благоустройство | статика | в коде |
| ServiceGrid | Сетка услуг с описанием и ценой «от» | благоустройство | статика | в коде |
| TrustStrip | Смета, сроки, гарантия (и аналоги) | главная, страницы услуг | статика | в коде |
| CTABand | Промежуточный призыв (выезд, скидка) | главная, страницы услуг | статика | в коде |
| LeadForm | Заявка, валидация, согласие на ПДн | главная, страницы услуг | остров | в коде (stub submit) |
| BeforeAfter | Сравнение до и после (пока плейсхолдеры фото) | благоустройство | статика | в коде (без JS до фото) |
| CaseGrid | Кейсы: фото-плейсхолдер + название + категория | благоустройство | статика | в коде |

| Testimonials | Отзывы / цитаты (плейсхолдеры) | благоустройство | статика | в коде |
| FAQ | Частые вопросы (`details`) | благоустройство | статика | в коде |
| PolicyContent | Текст политики конфиденциальности | политика | статика | согласовано (wireframe) |
| Базовые элементы | Кнопки, поля, заголовки секций | все | статика | в коде на страницах |

## Отложено (не MVP главной / четырёх страниц)

| Компонент | Почему отложен |
|---|---|
| Calculator | Цены «от» в карточках и заявка достаточны на старте |
| Contacts и карта | Контакты в footer; отдельная страница контактов не в карте из 4 страниц |
| Breadcrumbs | Можно добавить на внутренние позже для SEO |
| Gallery и Lightbox | Достаточно сетки кейсов и BeforeAfter; lightbox — по необходимости |
| Day/Night toggle на фото | Есть у Karagay; нужен контент по освещению — не MVP |
| Project story page | Editorial layout LWLA; пока сетка кейсов на странице направления |
| BriefForm (расширенный бриф) | Urban Green; в MVP хватает короткой LeadForm |
| Awards / блог / Perspectives | Не в карте из 4 страниц; отвлекают от заявки |
| CaseFilter (остров) | Категории есть в данных; интерактивный фильтр — когда фото и кейсов станет много |
| `/remont-kvartir` полный набор | Та же схема блоков; контент — плейсхолдеры |

## Решения по открытым вопросам

- **Цены:** отдельной страницы «Цены» нет; диапазоны «от» в карточках услуг + форма расчёта.
- **Два направления:** общая фирма (`#2E2E2E`, `#ED581F`); различие — ambient-tint (зеленоватый / тёплый) и контент; на главной — DirectionChooser, не пункты в шапке.
- **Главная обязательно:** Header, HeroIntro, DirectionChooser, DirectionPreview, TrustStrip, CTABand/LeadForm, Footer.
- **`/blagoustrojstvo`:** DirectionHero → TrustStrip → ServiceGrid → BeforeAfter → CTABand → CaseGrid → About → Testimonials → FAQ → LeadForm.
