# Референс: Advantages (septik-project)

- **Источник:** https://github.com/vladimirplyukhin89/septik-project — `web/src/components/Advantages.astro`, стили `.advantages-bento` / `.advantage-card` в `web/src/styles/global.css`
- **Что это:** блок преимуществ на сайте монтажа септиков. Разбор только этой секции, не всей страницы.
- **Что нравится:** шапка с надзаголовком; bento, где первая карточка крупнее; номер, крупный номер-водяной знак и короткая черта над заголовком
- **Что не берём:** тексты и лид референса; синий акцент и тёмный фон карточек; отдельный скрипт появления (`advantagesMotion.ts`: blur, stagger, scale). Тексты Монолита не меняем

## Структура блока

1. Надзаголовок и заголовок секции
2. Сетка карточек: номер, черта, заголовок, короткий текст. Первая карточка выделена размером и мягким градиентом

## Компоненты

| Компонент | Назначение | Состав | Варианты и состояния | Статика или остров |
|---|---|---|---|---|
| Advantages | Список опорных пунктов | надзаголовок, заголовок, карточки с номером и чертой | первая карточка крупнее; hover — обводка и тень; появление через Motion | статика разметки + скрипт появления |

Для monolit тот же блок уже есть: `TrustStrip`, статика без отдельного скрипта.

## Токены

- **Цвета референса:** акцент около `#0B6E99`, тёмная поверхность карточки, приглушённый текст. Для monolit не копируем: акцент остаётся `--color-primary`, карточка — `--color-bg`, текст — `--color-text` / `--color-text-muted`, граница — `--color-border`.
- **Типографика:** мелкий номер с разрядкой, крупный водяной знак, заголовок карточки жирнее обычного текста. На monolit — существующие `--font-size-*`.
- **Сетка:** одна колонка, с 640px две (первая на всю ширину), с 1024px три колонки и первая карточка на две колонки и две строки.
- **Формы:** радиус карточки около 1.15rem, тонкая граница, тень при наведении. На monolit — `--radius-xl` и уже существующий класс `glow`.

## Адаптивность

- Узкий экран: карточки столбиком.
- Шире: первая карточка занимает всю строку, остальные встают рядом.
- На широком экране при трёх пунктах первая карточка высокая слева, две остальные справа. При четырёх — первая на всю ширину, три остальные в ряд.

## Интерактив

- Hover карточки у референса меняет обводку и тень. Появление: карточки, номера и заливка черты через Motion, с учётом `prefers-reduced-motion`.
- Для monolit: hover через `glow`, вход карточек через уже подключённый `reveal`. Черта заполняется CSS `animation-timeline: view()`; без поддержки и при reduced motion она сразу полная. Отдельный JavaScript не нужен.

## Доступность и SEO

- Иерархия: один `h2` секции, заголовки пунктов — `h3`. Номера декоративные (`aria-hidden`): оранжевый `#F28C28` на белом не дотягивает до WCAG AA, поэтому смысл пункта несёт заголовок.
- Текст пунктов: `#222222` и `#5C5C5C` на `#FFFFFF` — контраст достаточный. Надзаголовок — приглушённый текст, не оранжевый.
- Карточки не кликабельны: отдельных зон нажатия нет.

## Решения для monolit

- Переносим в `TrustStrip`: надзаголовок, bento (3 и 4 пункта), номер, водяной знак, черта, выделение первой карточки градиентом от `--color-primary`.
- Новый компонент в инвентарь не добавляем. Тип остаётся статикой.
- Токены не меняем: номера, градиент и черта собираются через `color-mix` от уже согласованных цветов.
