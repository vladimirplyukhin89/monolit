# Референс: география.рф

- **Источник:** https://география.рф/ (`https://xn--80afahr7ap7a8g.xn--p1ai/`)
- **Что это:** сайт застройщика (новостройки, проекты, ипотека, заявка)
- **Что нравится:** шрифт и масштаб заголовков; крупные блоки с мягким скруглением; светло-серый ambient-фон страницы; спокойный вертикальный ритм секций; плавные переходы фона и состояний
- **Что не берём:** эмодзи и 3D-стикеры; градиенты «лайм → розовый»; фирму и тексты застройщика; сложные фильтры квартир и ипотечные калькуляторы

## Структура страницы

1. Sticky header: логотип, иконки, бургер / телефон
2. Hero-слайдер с крупным оффером на цветном/градиентном фоне
3. Промо-карточки (рефералка, ипотека и т. п.)
4. Подбор квартиры (фильтры + результаты)
5. Сетка проектов
6. О компании (цифры, короткий текст)
7. Новости
8. Форма «Получить консультацию»
9. Footer: колонки ссылок и контакты

## Токены

Промерено через computed styles (2026-11-11):

- **Цвета:**
  - фон страницы (ambient): `rgb(232, 232, 232)` / `#e8e8e8`
  - поверхности карточек / промо-плит: `rgb(255, 255, 255)` / `#ffffff`
  - основной текст: `rgb(20, 20, 20)` / `#141414`
  - акценты референса (не переносим): лайм `rgb(234, 255, 80)`, фиолетовые бейджи, тёмные плашки `rgb(20, 20, 20)`
  - для monolit: акцент и текст — фирменные `#F28C28` и `#222222`; ambient страницы `#e8e8e8` (`--color-bg-muted`), белые секции/карточки — `#ffffff` (`--color-bg`)
- **Типографика:** на сайте — TT Norms Pro (400/500/700). H1 ~32px (mobile), H2 ~26–30px, вес 500. Межстрочный у заголовков плотный (~1.2). В monolit — TT Norms через `--font-tt-norms` (лицензия у заказчика).
- **Сетка и отступы:** широкие вертикальные промежутки между секциями; контент в крупных «плитах» на сером ambient; на mobile блоки почти на всю ширину.
- **Формы:** крупные радиусы у карточек и кнопок (оценка 10–16px у промо, 16–24px+ у крупных плит); без тяжёлых многослойных теней.

## Адаптивность

- Mobile-first: на узком экране шапка компактная (иконки + бургер), hero на весь экран, карточки в одну колонку.
- На desktop сетки проектов и промо — в несколько колонок, тот же серый ambient и крупные плиты.

## Интерактив

- Слайдер hero, sticky header при скролле, hover у карточек.
- Фильтры и формы — клиентский JS.
- Для monolit из этого полезны: плавная смена фона (ambient), sticky header, минимум JS вне островов.

## Изображения и медиа

- Крупные фото проектов с обрезкой под карточку.
- Hero чаще с иллюстративным/градиентным фоном, чем с «сырым» фото.
- Для monolit: фото объектов, до/после; без декоративных эмодзи референса.

## Доступность и SEO

- Контраст текста на светло-сером фоне у референса в целом достаточный.
- Для monolit проверить: `#2E2E2E` на зеленоватом/тёплом ambient; `#ED581F` на белом и на tint-фонах (крупный текст/кнопки); мелкий оранжевый текст на tint — риск, лучше тёмный текст + оранжевый акцент на кнопках.
- Иерархия заголовков на референсе местами декоративная (много H3 у фильтров) — на monolit держать один H1 и логичные H2 секций.

## Решения для monolit

- Переносим: серый ambient страницы + белые «плиты» компонентов (`--color-bg: #ffffff` на light), крупные скруглённые секции, масштаб заголовков, плавные переходы фона.
- Не переносим: визуальный «игровой» слой, чужую палитру (лайм/фиолет), эмодзи и 3D-стикеры.
- В инвентарь: усилить идею ambient-фона; `DirectionChooser` как свой паттерн (у референса нет аналога двух направлений).
- Токены light: `--color-bg-muted` = `#e8e8e8`, `--color-bg` / `--color-surface` = `#ffffff`. См. `docs/design/tokens-proposal.md`.
