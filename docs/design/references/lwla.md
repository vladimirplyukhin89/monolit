# Референс: LWLA

- **Источник:** Behance https://www.behance.net/gallery/192109743/LWLA-Brand-Identity-and-Website · живой сайт https://www.lwladesign.com/
- **Что это:** бренд и сайт студии landscape design / installation / management (США); фото-first, editorial layout
- **Что нравится:** sweeping-фото на весь экран; спокойная типографика и воздух; один явный CTA Contact; страница проекта как монография (текст → сетка фото → цитата); список Perspectives без шумных карточек
- **Что не берём:** чужой бренд и тексты; cream/beige как основной фон (конфликт с уже выбранным серым ambient monolit и риск «AI cream»-штампа); глубокий блог/perspectives в MVP; нишу ecological restoration как копируемый tone of voice

## Структура страницы

Главная (живой сайт):

1. Transparent header: лого LWLA, Projects / Practice / People / Perspectives, кнопка Contact
2. Full-bleed hero-слайдер featured-проектов (название + пагинация точек)
3. Далее по сайту — разделы практики, людей, перспектив (не всё нужно monolit)

Страница проекта (из кейса):

1. Заголовок проекта + локация
2. Короткий нарратив / оффер кейса
3. Асимметричная сетка фото (вертикали + горизонтали)
4. Цитата / социальное доказательство
5. Продолжение галереи full-bleed

Perspectives:

1. H1 + фильтр категорий (All / Events / …)
2. Хронологический список: дата | заголовок (линии-разделители, без превью-карточек)

## Токены

- **Цвета:** тёплый off-white/cream верх; чёрный текст; UI на hero — белый текст и белая/чёрная кнопка Contact. Для monolit фон страницы остаётся `--color-bg-muted` `#E8E8E8`, не cream; CTA — `#ED581F`, не чёрная плашка.
- **Типографика:** крупный гротеск, много negative space; заголовки не перебивают фото.
- **Сетка:** spare layouts, асимметрия фото; широкие поля.
- **Формы:** на кейсе акцент на Contact как вход; детали формы на monolit — свои (`LeadForm`).

## Адаптивность

- Desktop: фото edge-to-edge, текст в колонке.
- Mobile (оценка): меню в бургер, hero на весь экран, фото столбиком — паттерн совместим с mobile-first monolit.

## Интерактив

- Hero carousel (dots + next).
- Подчёркивание active в навe/фильтрах.
- Для monolit: слайдер на главной не обязателен (у нас DirectionChooser); на `/blagoustrojstvo` — статичная галерея/кейсы без обязательного каруселя.

## Изображения и медиа

- Высокое качество, naturalistic meadows / paths / boardwalks; фото несёт бренд.
- Full-bleed и крупные кадры без оверлеев-стикеров.
- Для monolit: тот же принцип «фото объекта = якорь»; без копирования чужих проектов.

## Доступность и SEO

- Белый текст на фото: нужен градиент/затемнение под текст — проверить контраст.
- Skip-links на живом сайте — хороший ориентир.
- Один H1 на страницу проекта; Perspectives не раздувать до обязательного раздела monolit.

## Решения для monolit

- Переносим: фото-first секции без карточного шума; один доминирующий CTA; на кейсе — история + сетка фото (+ testimonials как цитата, когда будет контент); спокойный вертикальный ритм рядом с ambient Географии.
- Не переносим: cream-фон, чёрный Contact вместо оранжевого, обязательный blog/perspectives, прозрачный header как must-have (у monolit телефон + заявка важнее editorial minimal nav).
- В инвентарь: `CaseCard`/страница кейса — enriched story layout опционально позже; сейчас достаточно сетки кейсов на странице направления; `Testimonials` оставить под цитаты.
- Токены: без сдвига в cream; ambient landscaping уже зеленоватый — достаточно.
