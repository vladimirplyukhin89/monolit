# Референс: Urban Green

- **Источник:** https://www.behance.net/gallery/168554519/sajt-dlja-Urban-Green
- **Что это:** сайт ландшафтной компании с несколькими направлениями (студия, благоустройство, школа, фестиваль); Екатеринбург; агентство Creative Engineering / Voskhod и др.
- **Что нравится:** интро как визуальное меню услуг (явный fork направлений); проектные страницы с метриками; спокойный список проектов с фильтром; форма-бриф под заявку
- **Что не берём:** 3D/WebGL-интро и тяжёлый motion; горизонтальный скролл галерей; декоративные «звёзды» и clay-иллюстрации как основной язык; чужой бренд и контент; awards-театр вместо доверия для local lead-gen

## Структура страницы

1. Интерактивное intro: полноэкранные сцены направлений (парки, озеленение кровли и т. п.) — одновременно меню услуг
2. Переход в вертикальные информационные страницы
3. Проекты: список с фото/акцентами, фильтр (город, тип), «загрузить ещё»
4. Карточка проекта: фото, нарратив, метрики (кустарники, сроки, высота и т. п.)
5. О компании / команда / награды
6. Блог
7. Форма-бриф: контакты, объект, площадь, чекбоксы услуг и типа основания
8. Footer: телефон, email, адрес, соцсети

## Компоненты

| Компонент | Назначение | Состав | Варианты и состояния | Статика или остров |
|---|---|---|---|---|
| ServiceIntro / chooser | Выбор направления | полноэкранная сцена, заголовок, CTA «смотреть проекты» | слайд/сцена active | остров (у референса тяжёлый) |
| ProjectList | Портфолио | строки: название, фото, стрелка | hover, load more | статика (+ остров фильтр) |

## Токены

- **Цвета:** светло-серый `#F0F0F0` / off-white; чёрный текст; акцент sage/pistachio green на баннерах и геометрических пятнах. Для monolit зелёный только как ambient-tint благоустройства, не как primary CTA (`#ED581F`).
- **Типографика:** крупный all-caps для секций; тонкие линейные разделители; гротеск.
- **Сетка:** много воздуха; на mobile — вертикальный список проектов; тонкие 1px линии.
- **Формы:** острые/малые радиусы у референса; у monolit — крупные радиусы из токенов Географии (`--radius-lg/xl`).

## Адаптивность

- Mobile-мокапы сильные: список проектов, фильтр-оверлей, бриф.
- Desktop intro завязан на широкий canvas и motion — плохо стыкуется с SSG + минимум JS.

## Интерактив

- 3D/анимированное intro, прогресс-бар сцен, горизонтальный скролл на image-страницах, фильтр, load more.
- Для monolit: идея «chooser = меню направлений» уже в `DirectionChooser`; без WebGL и гориз. скролла.

## Изображения и медиа

- Смесь: clay/low-poly 3D, линейная графика, реальные фото объектов.
- Метрики рядом с фото кейса.
- Для monolit: только реальные фото работ (или плейсхолдеры); 3D-стиль не берём.

## Доступность и SEO

- Крупный декоративный текст на фоне рискует конкурировать с H1 — на monolit не повторять.
- Фильтр и бриф должны быть доступны с клавиатуры; чекбоксы с видимым фокусом.
- Горизонтальный скролл и canvas ухудшают SEO/производительность — для monolit неприемлемы как основа.

## Решения для monolit

- Переносим: паттерн «выбор направления = крупные равные панели» (уже в wireframe главной); на странице направления — список/сетка кейсов + опциональный простой фильтр; блок метрик внутри кейса или About; не усложнять LeadForm до полного брифа в MVP (достаточно имени, телефона, согласия; тип услуги — позже).
- В инвентарь: уточнить `CaseCard` (фото + название + опционально метрики); `DirectionChooser` усилить смыслом «меню направлений», не копируя 3D-интро.
- Не переносим: WebGL, awards как обязательный блок, sage как primary, декоративные геометрические фигуры поверх фото.
