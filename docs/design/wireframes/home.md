# Wireframe: главная и схема внутренних страниц

- **Приоритет:** главная `/`
- **Карта сайта:** `/` · `/blagoustrojstvo` · `/remont-kvartir` · `/politika-konfidencialnosti`
- **Стиль блоков:** крупные секции на фоне темы (light/dark); без сетки мелких карточек в первом экране
- **Контент:** благоустройство — из Tilda; ремонт — плейсхолдеры до материалов заказчика

## Тема сайта

- Light / dark: `data-theme` на `<html>`, переключатель `ThemeToggle` в Header.
- Фон page-shell всегда `--color-bg-muted` текущей темы (не tint направления).

## DirectionChooser (главная)

| Состояние | Карточка | Фон страницы | Ниже chooser |
|---|---|---|---|
| Нейтральное | обе с tint своего направления | muted темы | подсказка |
| Благоустройство | салатовый `#D5E8DA`, selected-обводка | muted темы | тизер landscaping |
| Ремонт | лаванда `#E2D8F0`, selected-обводка | muted темы | тизер renovation |

Акцент кнопок — `#F28C28`. Ритм светлая/тёмная **секция** на `/remont-kvartir` — см. `wireframes/remont-kvartir.md`.

### Поведение DirectionChooser

1. Клик по панели → состояние `selected`, tint остаётся на карточке (не на странице), открывается preview.
2. Повторный клик по другой панели → смена направления и тизера.
3. Клавиатура: обе панели — кнопки, фокус виден, Enter/Space переключают.
4. URL query `?dir=landscaping|renovation` без перезагрузки.
5. Ссылка на страницу направления — CTA в preview.

### Чего нет на главной (намеренно)

- Полный каталог всех услуг и FAQ — на страницах направлений
- Калькулятор, карта, отдельный блок контактов
- Мелкие чипы направлений в шапке как основной способ выбора

## Политика `/politika-konfidencialnosti`

Простая текстовая страница: Header → H1 → текст политики → Footer. Без DirectionChooser и ambient-tint направлений.

## Анимация и motion (минимум)

1. Переключение light/dark в Header (тема + anti-FOUC).
2. Лёгкий акцент selected-панели chooser (обводка/сдвиг), без шума.
3. Появление DirectionPreview (opacity/translate) при первом выборе.

Без параллакса, эмодзи и декоративных стикеров с референса.

## SEO на уровне структуры

- Главная: один H1 в HeroIntro (бренд + общее предложение); названия направлений в chooser — не второй H1.
- Страницы услуг: свой уникальный H1.
- Canonical, title, description — на каждую из четырёх страниц при вёрстке.
- JSON-LD LocalBusiness на главной; Service — на страницах направлений.
