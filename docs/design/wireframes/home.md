# Wireframe: главная и схема внутренних страниц

- **Приоритет:** главная `/`
- **Карта сайта:** `/` · `/blagoustrojstvo` · `/remont-kvartir` · `/politika-konfidencialnosti`
- **Стиль блоков:** крупные секции на ambient-фоне (идея с география.рф), без сетки мелких карточек в первом экране
- **Контент:** благоустройство — из Tilda; ремонт — плейсхолдеры до материалов заказчика

## Состояния ambient главной

| Состояние | `data-direction` | Фон страницы | Что видно ниже chooser |
|---|---|---|---|
| Нейтральное (старт) | отсутствует / `neutral` | серый muted (`--color-bg-muted`) | краткая подсказка «выберите направление» или оба тизера свёрнуты |
| Благоустройство | `landscaping` | лёгкий зеленоватый tint | тизер landscaping |
| Ремонт квартир | `renovation` | тёплый желтоватый tint | тизер renovation |

Переход фона: CSS `transition` на `background-color` у `body` / обёртки, 300–500 ms. Акцент кнопок и ссылок всегда фирменный оранжевый `#ED581F`; tint только атмосфера, не замена бренда.

### Поведение DirectionChooser

1. Клик по панели → `data-direction` на корне страницы, ambient меняется, панель получает состояние `selected`.
2. Повторный клик по другой панели → смена направления и тизера.
3. Клавиатура: обе панели — кнопки/`role="button"`, фокус виден, Enter/Space переключают.
4. Предпочтительно обновить URL hash или query (`?dir=landscaping`) без перезагрузки — чтобы можно было поделиться; не обязательно в MVP wireframe, заложить в реализацию.
5. Ссылка «на страницу направления» — отдельный CTA в preview, не вместо выбора ambient.

### Чего нет на главной (намеренно)

- Полный каталог всех услуг и FAQ — на страницах направлений
- Калькулятор, карта, отдельный блок контактов
- Мелкие чипы направлений в шапке как основной способ выбора

## Страница направления (схема)

Общая схема для `/blagoustrojstvo` и `/remont-kvartir`. Ambient страницы зафиксирован под направление (без переключателя на всю страницу; в шапке — ссылка на другое направление).

```
Header
Hero направления (H1, оффер, CTA заявки)
ServiceGrid (карточки услуг + «от», если есть)
BeforeAfter или Gallery (по наличию фото)
CTABand (выезд / скидка — формулировки с Tilda для благоустройства)
TrustStrip
CaseGrid (фильтр категорий — остров только если фильтр интерактивный)
About (текст + метрики)
Testimonials
FAQ (details)
LeadForm
Footer
```

**`/blagoustrojstvo`:** наполнение из `references/monolit-tilda-content.md`.  
**`/remont-kvartir`:** те же блоки, тексты и цены — плейсхолдеры `[Название услуги]`, `[от — ₽]`, `[текст]`.

## Политика `/politika-konfidencialnosti`

Простая текстовая страница: Header → H1 → текст политики → Footer. Без DirectionChooser и ambient-tint направлений.

## Анимация и motion (минимум)

1. Transition ambient-фона при смене направления (обязательная «изюминка»).
2. Лёгкий акцент selected-панели (масштаб/обводка/фон панели), без шума.
3. Появление DirectionPreview (opacity/translate) при первом выборе.

Без параллакса, эмодзи и декоративных стикеров с референса.

## SEO на уровне структуры

- Главная: один H1 в HeroIntro (бренд + общее предложение); названия направлений в chooser — не второй H1.
- Страницы услуг: свой уникальный H1.
- Canonical, title, description — на каждую из четырёх страниц при вёрстке.
- JSON-LD LocalBusiness на главной; Service — на страницах направлений.
