# Wireframe: `/remont-kvartir`

- **Референс структуры:** `docs/design/references/nikakih-nervov.md`
- **Токены:** вариант A + фирма `#F28C28` / `#222222` (`docs/design/tokens-proposal.md`)
- **Контент:** плейсхолдеры до материалов заказчика (`docs/content/remont-kvartir.md`)
- **Стиль блоков:** ритм светлая ↔ тёмная секция; без тёплой заливки всей страницы

## Фон страницы

| Зона | Фон | Текст |
|---|---|---|
| Page shell | `--color-bg` (`#ffffff`) или `--color-bg-muted` | `--color-text` |
| Светлые секции | `--color-bg` | `--color-text` (`#222222`) |
| Тёмные секции | `--color-bg-inverse` (`#222222`) | `--color-on-inverse` (`#ffffff`) |
| CTA / акценты | `--color-primary` (`#F28C28`) | см. контраст в tokens-proposal |
| Ambient главной | розовый tint только на карточке ремонта в DirectionChooser | не на этой странице |

Шапка: ссылка на другое направление (`/blagoustrojstvo`). Переключателя ambient на всю страницу нет.

### Опционально позже (не MVP порядка)

- BeforeAfter / галерея «пример реализации» — между ServiceGrid и CaseGrid, если появятся фото
- Testimonials — после About, по наличию отзывов
- CTABand между блоками — если нужен промежуточный оффер выезда
- TeamIntro, PartnersStrip, QuizCalculator — отложены в инвентаре

## Контраст секций (ритм)

Рекомендуемый чередующийся ритм:

1. Hero — тёмный (фото)  
2. Trust — светлый  
3. Package — светлый + оранжевая/тёмная плашка  
4. Services — светлый  
5. Cases — тёмный  
6. About — светлый  
7. FAQ — светлый  
8. Form — светлый / muted  

## SEO

- Один H1 в Hero
- Уникальные `title` / `description`
- JSON-LD `Service` (+ LocalBusiness при необходимости)
- `alt` у фото кейсов и hero
